I found several existing user configurations for MangoWC! Here are the repositories with actual user configurations:

## Official Example Configurations

1. **DreamMaoMao/mango-config** (Creator's official config)
   - Repository: https://github.com/DreamMaoMao/mango-config
   - Two branches available:
     - Main branch: Daily config
     - `dms` branch: DMS-specific config
   - Install with: `git clone https://github.com/DreamMaoMao/mango-config.git ~/.config/mango`

## Community Configurations

2. **bautitobal/mango**
   - Repository: https://github.com/bautitobal/mango
   - Nord-inspired Detective aesthetic
   - Optimized for productivity and clarity
   - Similar tiling behavior to Hyprland

3. **argosnothing/mango-dwm-config**
   - Repository: https://github.com/argosnothing/mango-dwm-config
   - Designed for DWM users transitioning to MangoWC
   - Includes config.conf, waybar config, and styling
   - Has a dev environment via Nix flake

4. **stovalche/mangowc-config**
   - Repository: https://github.com/stovalche/mangowc-config
   - Includes: config.conf, autostart.sh, envvars.conf
   - Has swaync integration (notification daemon)
   - Includes waybar configuration and scripts

5. **tonybanters/mangowc-btw** & **radiaku/mangowc**
   - Tutorial-based configurations from tonybtw.com
   - Includes waybar integration
   - Basic keybindings setup for beginners

6. **LonelyBoyAlex/Matfiles**
   - Repository: https://github.com/LonelyBoyAlex/Matfiles
   - Matugen-powered dotfiles
   - Supports multiple window managers including MangoWC, Hyprland, Niri, and Qtile

These repositories contain actual config.conf files, autostart scripts, and various integrations with tools like waybar, swaync, and other Wayland utilities.
