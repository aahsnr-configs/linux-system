# Custom Arch Install with the following properties:

- Full Disk Encryption,
- LUKS
- Dracut
- Limine
- Btrfs
- Snapper
- No LVM
- 1st partition boot (4192 MB)
- 2nd partition swap
- 3rd partition encrypted root (no LVM)
- Follow CachyOS btrfs subvolume structure
